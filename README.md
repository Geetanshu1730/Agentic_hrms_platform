# 🚀 Agentic AI Workforce Intelligence Platform

An enterprise-grade decision support platform combining predictive workforce modeling, semantic skill-gap diagnostics, RAG-based HR policy intelligence, and multi-agent workflow orchestration.

---

## 🌟 Live Demo
🔗 **Deployed Application:** `https://agentichrmsplatform-e59zezy6cbku4y3y773nmn.streamlit.app`

---

## 🛠️ Key Architectural Pillars

1. **Predictive Turnover & Performance Modeling**
   - Deep learning architectures trained using PyTorch with cost-sensitive loss calibration to forecast attrition risk (`LOW`, `MEDIUM`, `HIGH`).
2. **Semantic Skill-Gap & Upskilling Engine**
   - Natural language and TF-IDF semantic competency matching to evaluate employee readiness against target role requirements.
   - Dynamic generation of structured, week-by-week learning roadmaps.
3. **Enterprise Talent Heatmap & Quotas**
   - Macro organizational supply-vs-demand analysis for strategic reskilling vs. external hiring decisions.
4. **HR Policy Knowledge Retrieval (RAG)**
   - Retrieval-Augmented Generation layer enabling natural language search across corporate policy guidelines and handbooks.
5. **Agentic Orchestration Copilot**
   - Specialized agent routing (Policy Agent, Career Agent, Workforce Planning Agent) to automate HR inquiries and operations.
