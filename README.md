# 🚀 AI Workforce Intelligence Platform (Agentic HRMS)

An enterprise-grade, end-to-end decision-support platform designed to transform fragmented HR records into actionable, predictive talent intelligence.[cite: 1]

---

## 📌 Problem Statement
Traditional HR management systems store records across disconnected silos (HRMS, performance systems, learning platforms, and static policy documents), forcing leadership to make reactive talent decisions.[cite: 1] This platform provides automated, predictive intelligence across employee retention, career progression, and workforce planning.[cite: 1]

---

## ⚡ Core Features

* **🧠 Deep Learning Attrition Risk Engine**: Predicts employee turnover probability using PyTorch neural networks with calibrated threshold tuning and risk categorization (`LOW` / `MEDIUM` / `HIGH`).[cite: 1]
* **🎯 Semantic Skill-Gap Diagnostics**: Matches employee skills against target job profiles using semantic vector embeddings and NLP rather than brittle exact string matching.[cite: 1]
* **📚 Personalized Upskilling Engine**: Formulates structured, role-specific learning paths, tracks time-to-completion, and models post-training readiness trajectories.[cite: 1]
* **🏢 Organizational Talent Strategy & Heatmap**: Computes macro skill deficits across teams and generates data-driven hire-vs-reskill quotas.[cite: 1]
* **📖 HR Policy Knowledge RAG**: Retrieval-Augmented Generation layer enabling grounded, cited Q&A over company handbooks, leave policies, and benefits.[cite: 1]
* **🤖 Multi-Agent Orchestration Layer**: State-based agent routing to dispatch tasks across Policy, Career, and Workforce Planning agents.[cite: 1]

---

* **ML / Deep Learning**: PyTorch, Scikit-learn, Pandas, NumPy[cite: 1]
* **NLP / Search**: Vector Embeddings, TF-IDF Cosine Similarity, RAG[cite: 1]
